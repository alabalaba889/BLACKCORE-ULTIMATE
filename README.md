# BLACKCORE ULTIMATE — v0.1 prototype

Primeira base funcional para Windows 10 Pro x64, feita com Python e bibliotecas padrão.

## Recursos
- Interface escura estilo terminal hacker.
- Monitoramento básico de CPU e RAM.
- Botões para abrir Bloco de Notas e Calculadora.
- Digitação de texto no aplicativo ativo, após confirmação e contagem de 3 segundos.
- Trollagens apenas visuais, identificadas como simulação e fáceis de fechar.
- Log local das ações.

## Ainda não incluído
- Controle remoto por Android/internet.
- Controle remoto do mouse.
- Instalador .exe.
- Monitoramento de GPU, plugins ou reparação automática.

## Como executar
1. Instale Python 3 para Windows, se necessário: https://www.python.org/downloads/windows/
2. Durante a instalação, marque **Add python.exe to PATH**.
3. Baixe os arquivos pelo botão **Code → Download ZIP**.
4. Extraia o ZIP e dê dois cliques em `INICIAR_BLACKCORE.bat`.

O app não se instala sozinho nem roda escondido. A função de digitação pede confirmação e envia apenas o texto que você escreveu. Não use em senhas, pagamentos ou comandos sensíveis.
